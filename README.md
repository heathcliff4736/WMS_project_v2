## 🌿 브랜치 전략

### 브랜치 구조
```
main (배포용 - 최종 완성본만)
  ↑
develop (개발 통합 - 작업 중인 코드)
  ↑
dev/개인 branch (개인 작업 브랜치)
```

### 브랜치 네이밍 규칙
```bash
dev/개인 branch        # 예: dev/KHG
fix/버그명-이름        # 예: fix/signup-bug-KHG
docs/문서명-이름       # 예: docs/readme-update-KHG
refactor/대상-이름     # 예: refactor/api-KHG
```
